## GeneExprLupusMx.es

GeneExprLupusMx.es translates GeneExprLupusMx to es.

To use it, install GeneExprLupusMx.es and rdlocal

```r
pak::pak(c("eliocamp/rdlocal", "GeneExprLupusMx.es"))
```

Then, in your R session, load rdlocal and set your language 

```r
library(rdlocal)
Sys.setLanguage("es")
```

GeneExprLupusMx's documentation will now appear in your language.
